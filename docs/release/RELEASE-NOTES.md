UNALLOCATED 0.3.0 — a first-person horror mod for **Minecraft Java Edition 26.3** (Fabric), by NULL_Threshold Interactive.

## Install
- **Minecraft 26.3** with **Fabric Loader 0.20.1 or newer**, Java 25 (the launcher provides it).
- Put **only `unallocated-0.3.0.jar`** in your `mods` folder. Fabric API is already inside the JAR.
- **TLauncher / offline accounts work.** For a TLauncher custom version the folder is `.minecraft/versions/<version name>/mods`.
- Start the game, accept the contract (type **I agree** / **De acuerdo**, or click), then press **UNALLOCATED** above Singleplayer.
- Stuck? Type `/unallocated next` (`/unallocated siguiente`) in chat.
- Fallback: unzip `UNALLOCATED-world.zip` into `saves/` and open it from Singleplayer.

## What's new since 0.2.0
- **The Reclaimer has its own body**: a custom 3D model (a hunched human torso carried like a spider, eight jointed legs solved and stretched every frame, overlong arms, faces of its victims), its own textures with glowing eyes, and movement that drops frames.
- **Threads are the mod's own block**: animated, faintly lit, they vibrate when touched (louder if you run, silent if you sneak) and pull nearby stalkers toward you; shears cut them. Its own web and rot blocks replace vanilla cobweb, mud and soul soil.
- **Every sound is original**, synthesized from scratch (`tools/sounds/synth.py`): ambience, threads, the creature's clicks, steps, breathing, whispers and scream, glitches and screamers.
- **English and Spanish, complete**: story, contract, signs, book, endings and commands follow your game language.
- Story fixes: a late correct answer in the Kernel no longer turns into CONSUMED; the creature no longer leaks into the next chapter; Trial numbers are always right; consent is asked again on every trial; a guided watchdog window; the creature stalks before it charges.

Content warnings: flashing and flickering, loud sudden sounds, jump scares, psychological horror.
