### 2.4 The interface as a weapon: what a mod can change in 26.3 (read 2026-10-26)

Evidence: branch `26.3` of FabricMC/fabric-api (head as of this date, not the 0.165.0 tag), NeoForged porting primers, minecraft.wiki, Fabric blog and code from third-party mods compiled against 26.3.

**Name changes in 26.x that affect the whole UI lane:** in 26.1 `ResourceLocation` → `Identifier`, `GuiGraphics` → `GuiGraphicsExtractor`, `render*` → `extract*`/`extractRenderState`; in 26.2 `Gui` and `Hud` are split (screens with `Minecraft.getInstance().gui.setScreen()`, toasts in `Gui#toastManager`; chat, player list and F3 in `Hud`); in 26.3 SDL3 replaces GLFW. Sources: [Fabric 26.3](https://fabricmc.net/2026/09/15/263.html), [NeoForged primer 26.3](https://docs.neoforged.net/primer/docs/26.3/). **Tutorials predating 26.1 are obsolete** for this lane.
