# Archived generators

`story_v030.py` and `story_v040.py` generated the 0.3.0 and 0.4.0 chapter files. They are kept only as history.
**Do not run them**: since 0.5.0 the chapters in `src/main/resources/data/unallocated/story/chapters/` are edited
directly (and the Shell and boss fight live in `KernelShell.java`); running an old generator would overwrite them.
